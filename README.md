# NightComic

یک کاتالوگ آنلاین مانگا/مانهوا با رابط کاربری React (RTL، فارسی) و بک‌اند Express کامل: ثبت‌نام و ورود کاربر، پنل ادمین برای افزودن سری و فصل، آپلود تصویر جلد و صفحات فصل، و «لیست من» (بوکمارک) متصل به حساب کاربری.

## ساختار پروژه

```
nightcomic-main/
├── server.js            # بک‌اند Express (auth, admin, آپلود فایل, API)
├── bootstrap.js          # داده‌ی اولیه (seed) برای اولین اجرا
├── src/                   # فرانت‌اند React (Vite) — همه‌ی فایل‌ها مستقیم اینجان، بدون زیرپوشه
│   ├── App.jsx
│   ├── api.js
│   ├── main.jsx
│   ├── styles.css
│   └── ...View.jsx / سایر کامپوننت‌ها
├── storage/               # موقع اجرای سرور خودکار ساخته می‌شه (لازم نیست آپلودش کنی)
├── Dockerfile
├── railway.json
└── package.json
```

## اجرا در حالت توسعه

```bash
npm install
cp .env.example .env      # و مقادیرش رو عوض کن
npm run dev
```

این دستور هم سرور Express (پورت ۸۰۸۰) و هم Vite (پورت ۵۱۷۳) رو همزمان اجرا می‌کنه. توی مرورگر بری روی **http://localhost:5173** رابط کاربری رو می‌بینی؛ درخواست‌های `/api` و `/uploads` به‌صورت خودکار به سمت سرور Express فوروارد می‌شن.

روی اولین اجرا، دیتابیس JSON خالی با داده‌ی نمونه (۱۴ سری ساختگی) در `storage/data/db.json` ساخته می‌شه و یک حساب ادمین بر اساس `ADMIN_USERNAME` / `ADMIN_PASSWORD` (پیش‌فرض: `admin` / `admin123`) ساخته می‌شه — حتماً قبل از انتشار عمومی این رمز رو عوض کن.

## ساخت نسخه‌ی نهایی (production)

```bash
npm run build   # فرانت‌اند رو داخل dist/ می‌سازه
npm start       # سرور Express رو اجرا می‌کنه؛ چون dist/ وجود داره، همون رو هم سرو می‌کنه
```

با این حالت فقط یک سرویس (پورت ۸۰۸۰) هم API و هم رابط کاربری رو سرو می‌کنه — همون چیزی که برای دیپلوی لازمه.

## دیپلوی

پروژه با **Dockerfile** و **railway.json** آماده‌ی دیپلوی روی Railway یا هر پلتفرم دیگه‌ایه که از Docker پشتیبانی می‌کنه:

1. ریپو رو به گیت‌هاب پوش کن.
2. یک سرویس جدید روی Railway (یا مشابه) از روی همین ریپو بساز.
3. متغیرهای محیطی `SESSION_SECRET`، `ADMIN_USERNAME`، `ADMIN_PASSWORD` رو تنظیم کن.
4. اگه پلتفرم یک **Volume** پایدار پیشنهاد می‌ده، اون رو روی مسیر `/app/storage` مونت کن تا دیتابیس و تصاویر آپلودی بعد از هر دیپلوی جدید از بین نرن.

## API خلاصه

| مسیر | توضیح |
|---|---|
| `POST /api/register` | ساخت حساب کاربری |
| `POST /api/login` / `POST /api/logout` | ورود / خروج |
| `GET /api/works` | فهرست همه‌ی سری‌ها به همراه فصل‌ها |
| `GET /api/works/:id` | جزئیات یک سری |
| `GET /api/chapters/:id/pages` | صفحات یک فصل |
| `POST /api/works/:id/favorite` | افزودن/حذف از لیست من (نیاز به ورود) |
| `POST /api/admin/works` | افزودن سری جدید (ادمین، multipart با فیلد `cover`) |
| `POST /api/admin/works/:workId/chapters` | افزودن فصل (ادمین) |
| `POST /api/admin/works/:workId/chapters/:chapterId/pages` | آپلود صفحات فصل (ادمین، multipart با فیلد `pages`) |

## آپلود از موبایل به گیت‌هاب

اگه از گوشی آپلود می‌کنی، پوشه‌ها رو تک‌تک اضافه کن (نه با کشیدن کل zip):

1. یه ریپوی خالی جدید بساز.
2. توی صفحه‌ی ریپو → **Add file → Upload files** → همه‌ی فایل‌های ریشه (`package.json`, `server.js`, `bootstrap.js`, `index.html`, `vite.config.js`, `Dockerfile`, `railway.json`, `README.md`, `.gitignore`, `.env.example`) رو با هم انتخاب و آپلود کن.
3. دوباره **Add file → Upload files** → این‌بار برو داخل پوشه‌ی `src` روی گوشی و همه‌ی فایل‌های داخلش رو انتخاب کن. قبل از Commit، توی گیت‌هاب یه‌بار مسیر مقصد رو چک کن که واقعاً `src/...` باشه (بعضی مرورگرهای موبایل فایل‌ها رو توی ریشه می‌ریزن اگه دقت نکنی).
4. بعد از آپلود، مطمئن شو که آدرس `github.com/USERNAME/REPO/tree/main/src/main.jsx` واقعاً باز میشه و خالی نیست.

اگه این مرحله‌به‌مرحله رو رعایت نکنی، معمولاً فایل‌های داخل `src` گم می‌شن یا توی ریشه پخش می‌شن و بیلد روی Railway با خطای «نمی‌تونم `src/main.jsx` رو پیدا کنم» شکست می‌خوره.

## نکات

- داده‌ها در یک فایل JSON ساده (`storage/data/db.json`) ذخیره می‌شن — برای شروع و پروژه‌های کوچیک کافیه؛ برای مقیاس بزرگ‌تر بعداً می‌شه به یک دیتابیس واقعی (Postgres/SQLite) مهاجرت کرد.
- فایل‌های آپلودی و دیتابیس داخل `.gitignore` هستن؛ یعنی توی خود ریپوی گیت‌هاب آپلود نمی‌شن (همون‌طور که باید باشه).
- اگه برای یک سری تصویر جلد آپلود نشه، جلد گرادیانیِ خودکار (بر پایه‌ی `hue`) به‌جاش نمایش داده می‌شه — دقیقاً همون افکتی که در نسخه‌ی اولیه‌ی دموی فرانت‌اندی وجود داشت.
